# Nevorai CRM site (crm.nevorai.com)

Plain static site, no build step: `public/` is served as is (see `vercel.json`).
- `/` Nevorai CRM home, `/agencies/` the agencies sales page.
- Plan buttons link to billing.nevorai.com/buy/agency (Kaizen). Prices: Growth 4,999 / Pro 10,999 + GST.
- Screens in `public/img` are real captures of the Agencies app in demo mode.
- The old personal CRM (FastAPI) is kept in git as tag `old-personal-crm-backup` and on `main` until launch.
